# 晴屿 · 多 Agent 青少年情绪自助研究原型

原创实现项目申请书 §5.1–5.3 的核心流程，参考所提供 HTML 的浅绿、自然、温柔视觉方向。本地开发使用 Python 标准库 + 原生前端；服务器部署使用 Gunicorn 与 Docker。

## 启动
```sh
python3 server.py
```
打开 http://localhost:8000 。请勿直接双击 HTML；需要服务端运行。

## 可选模型
支持 OpenAI-compatible Chat Completions 服务。在服务端环境中配置 `LLM_API_KEY`、`LLM_BASE_URL`（以 /v1 结尾）、`LLM_MODEL` 后再启动。密钥不写入浏览器或仓库。默认地址 https://api.openai.com/v1，默认模型 gpt-4.1-mini，可自行替换。模型不可用时回退模板；风险疑似表达会保守进入人工支持。

无密钥时各模块使用规则运行；界面明确显示运行模式，绝不将规则称为语义理解。

## 具体设计
- `engine.py`：集中编排器，监测 → 风险 → 检索 → 引导；中高风险直接转介，阻断一般干预；本次会话持续安全支持，避免下一轮自动回到常规练习。
- 监测模块：自报强度及跨轮变化、表达参与线索、认知反思线索。不是量表或临床情感分析。
- 风险模块：三级规则研判，可选 LLM 语义通道，取较高等级；异常走保守路径。
- 转介模块：确定性安全回应与脱敏摘要。不发送监护人通知。
- 引导模块：四阶段推进、CBT/BA/ER/PST 策略和可选模型生成，输出启发式审查。
- 知识：评估、分类、策略、模板四层演示条目；关键词排序与 ID 溯源。尚无向量嵌入，不声称完成论文提出的 RAG。
- 前端：青少年对话、工具箱、逐轮协作轨迹、状态查看与脱敏摘要导出。

## 演示
1. 输入“考试没考好，我觉得自己很失败”，查看 CBT-01 引用。
2. 开新对话，输入“最近什么都不想做，只想躺着”，查看 BA-01。
3. 连续对话，观察四阶段与强度变化；将强度从 5 提高到 9 查看节奏调整。
4. 输入虚构的明显风险表达，查看引导被阻断、转介优先执行及未发送通知标记。

## 测试
```sh
python3 -m unittest discover -s tests -v
```
这些仅是工程分支测试，不能代表风险识别性能、临床效果或研究目标达成。

## 上传 GitHub
创建仓库并上传本目录全部文件即可。不要上传申请书、真实对话、个人资料、密钥或 .env。
GitHub 保存源代码；GitHub Pages 不能运行 Python 后端。EdgeOne Pages（Python Cloud Functions）和腾讯云服务器两种部署步骤见 [DEPLOY.md](DEPLOY.md)，已经提供 Dockerfile、Compose、Caddy HTTPS 和 GitHub 自动检查配置。

生产入口为 `app:application`；`server.py` 仅用于本机预览。配置模型时默认要求设置 `DEMO_ACCESS_CODE`。不在浏览器中保存模型密钥。

## 研究边界
这是功能原型，不用于临床和真实未成年人试验。知识条目为人工示例，未完成文献与专家核验。阶段按轮数推进，参与度与认知线索为启发式，规则及语义模型均可能漏报或误报，输出审查亦非可靠安全防线。尚未实现 PHQ-A/GAD-7、向量库、自动通知、专家评审与临床验证，不展示虚构研究指标。

会话由服务端内存管理，闲置一小时后清理；刷新页面不一定清空会话，服务重启会清空。配置模型后，近六轮对话会发送给配置的服务商。导出只含状态、风险等级和策略 ID，不含原始对话。申请书的个人联系方式未纳入代码。
